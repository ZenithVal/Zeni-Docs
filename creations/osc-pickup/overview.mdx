# OSC Pickup
A VRChat tool for avatar pickup with OSC and OpenVR playspace movement. <br/>
No world integration needed ~ Just an avatar gimmick!

This tool is not for larger scale movement/travel across worlds ~ try out [OSCLeash](github.com/ZenithVal/OSCLeash) for that.

# Requirements
- Windows 10/11 (Linux potentially, if requested?)
- SteamVR with an OpenVR compatible headset 
- Full Body Tracking required (Sorry! :c)
- An avatar with the OSCPickup prefab

# Warnings
- Motion sickness warning.
- May run into issues if VRChat is running at < 20 FPS
- This application edits your playspace to move you around so your chaperone bounds may become inaccurate.
  - If you don't have [OVRAS](https://store.steampowered.com/app/1009850/OVR_Advanced_Settings) you shouldn't disable ResetToZero.
- Still actively in production. Some lingering issues I need to work on.    

Heavily recommended you also have OVR Advanced settings to backup reset your playspace offsets! <br/>
