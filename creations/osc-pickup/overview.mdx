# OSC Pickup
A VRChat tool for avatar pickup with OSC and OpenVR playspace movement. <br/>
No world integration needed ~ Just an avatar gimmick!

This tool is not for larger scale movement/travel across worlds ~ try out [OSCLeash](github.com/ZenithVal/OSCLeash) for that.

# Requirements
- Windows 10/11 (Linux potentially, if requested?)
- SteamVR with an OpenVR compatible headset 
- Full Body Tracking required (Sorry! :c)
- An avatar with the OSCPickup prefab

# Known issues
- Poor grab accuracy if FPS is Low (< 20 FPS)
- Incompatible with OVR Advanced Settings > 5.7.4.
- Incompatible with other playspace movers.
  - IF you have OVRAS on Steam, you can right click it, go to properties, and select the "Betas" tab. 
  - From there you can select the 5.7.4 to downgrade.
- Currently the chaperone is not counter offset. Your chaperone bounds **WILL** become inaccurate while using. 
- Some playspaces are inverted(?) Havn't narrowed down the cause for this but 
  - If you're always flying off, you can set `InvertedSpace` to true in the config.

Heavily recommended you also have OVR Advanced settings to backup reset your playspace offsets! <br/>
